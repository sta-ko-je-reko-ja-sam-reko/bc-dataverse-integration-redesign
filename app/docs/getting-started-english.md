# Getting started

1. Install Microsoft **Field Service Integration** (version 29.0 or later) and this app.
2. Set up the Dataverse connection as usual (*Dataverse Connection Setup*), then Dynamics 365 Sales and/or
   Field Service if you use them.
3. Turn on the redesigned integration and choose the mappings that use it:
   [FEAT-DVI-001 - Core Pipeline](FEAT-DVI-001-CorePipeline/getting-started-english.md).

This guide grows with each delivered feature.
